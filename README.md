# WoSB_DB_Editor — репозиторий БД каталога WoSB

Единый источник правды о каталоге игры (предметы, рецепты,
мануфактуры). Формат и роли сторон описаны в [SCHEMA.md](SCHEMA.md).

## Структура

| Путь | Назначение |
|---|---|
| `catalog.json` | **Сама БД** — формат v2 (ключ `craftTime` с v0.3; секция `groups` с v0.2; kind групп и флаги материалов с v0.4; kind `ammunition` и флаг `isAmmoMaterial` с v0.5) |
| `renames.json` | Append-only журнал переименований — устройство мигрирует пользовательские данные при «Обновить БД» |
| `texts.json` | Переопределения текстов интерфейса приложения (wosb-android-75) — заголовки/подсказки экранов, тексты настроек; файл хранит ТОЛЬКО отличия от встроенных дефолтов |
| `SCHEMA.md` | Описание формата, правил валидации и жизненного цикла правок (v0.5) |
| `tools/validate_catalog.py` | Валидатор: правила `CatalogParser` приложения + поиск циклов в рецептах + groups/renames + флаг опасных вод + правила крафт-юнитов (v0.4) и боеприпасов (v0.5) |
| `.github/workflows/validate.yml` | CI: валидация при каждом push/PR |

## Как это работает

1. **Админ** правит БД в скрытой админке приложения (Android) и
   коммитит `catalog.json` сюда через GitHub Contents API
   (fine-grained PAT `contents:write` только на этот репозиторий).
2. **CI** валидирует файл (схема, ссылки, циклы) — красный коммит
   в обновления не попадает.
3. **Приложение** предлагает пользователям «Обновить БД» по последнему
   зелёному коммиту `main`; перед применением повторно валидирует файл
   локально. Встроенная копия в APK — фолбэк для первого запуска и
   оффлайна.

Git-история репозитория = полный журнал изменений БД.

Локальная проверка:

```bash
python3 tools/validate_catalog.py catalog.json renames.json texts.json
```

## Статус

Схема **v0.5** — решения владельца зафиксированы (SCHEMA.md §10):
один файл, уровни ровно 4, группы — данные, имена-ключи + протокол
переименования; крафт-время в единицах (ключ `craftTime`, формат 2);
у мануфактур флаг `availableInDangerousWaters` (значение за владельцем);
v0.4: группы получают kind (resources/tools/ships), у ресурсов флаги
«Материал для орудий/кораблей», крафт-юниты без веса и времени, у
кораблей выход 1, группа 1 переименована «Предметы» → «Ресурсы».
Код приложения (скрытая админка, синк, обновления БД, редактор
с семантикой групп) — wosb-android-43.
v0.5 (wosb-android-79): kind `ammunition` и seed-группа 4
«🧨 Боеприпасы» (тоже только крафт, но с весом и крафт-временем —
вес партии нужен смете), у ресурсов флаг «Материал для боеприпасов»
(`isAmmoMaterial`).
